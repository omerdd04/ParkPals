# 🐾 Dog parks — פארק כלבים חברתי

אפליקציה חברתית לבעלי כלבים בישראל: מפת פארקי כלבים ארצית, סטטוס חי של מי בפארק,
תיאום סיבובים בלחיצה אחת, אקדמיה לכלב, מד שמחה ותיבת תלונות פארקים.

> גרסה 0.1 — אב-טיפוס עובד (frontend בלבד, נתונים נשמרים מקומית במכשיר).

## התכונות

- **🗺️ מפה ארצית** — פארקי כלבים לפי ערים (Leaflet + OpenStreetMap), עם עיגולים
  צפים של הכלבים שנמצאים בפארק עכשיו (כמו סטוריז).
- **🟢 סטטוס נוכחות** — "אני בפארק" (נעלם אוטומטית אחרי שעה) או "יוצא לפארק
  ב-15 הדקות הקרובות", עם אפשרות לשיתוף מיקום חי.
- **💬 צ'אט מהיר בלי הקלדה** — רק כפתורים: הזמנה לסיבוב ותשובות אוטומטיות
  (כן מגיע / לא הפעם / פעם הבאה / פספסנו).
- **👥 חברים** — קוד אישי + QR לשמירה מהירה, חברים מועדפים עם התראות אוטומטיות.
- **🎓 אקדמיה** — 5 שיעורים קצרים (אילוף גור, 5 פקודות בסיס, כמות אוכל, מותר/אסור,
  אתיקה בפארק).
- **😊 מד שמחת הכלב** — גיימיפיקציה: תיעוד סיבובים, מים, אוכל, חטיפים ועוד מעלה את
  ציון השמחה היומי.
- **📮 תיבת תלונות פארקים ארצית** — דיווח על בעיות בפארקים, לשיתוף עם הרשויות.
- **📋 שאלון היכרות** — איסוף מידע על הבעלים והכלב בכניסה הראשונית.

## הרצה מקומית

```bash
npm install
npm run dev       # שרת פיתוח
npm run build     # בנייה לפרודקשן (כולל בדיקת טיפוסים)
npm run preview   # תצוגה מקדימה של הבנייה
```

## סטאק טכנולוגי

- **React 18 + TypeScript + Vite**
- **Tailwind CSS** — עיצוב mobile-first, RTL מלא
- **Leaflet / react-leaflet** — מפה (ה-CSS מצורף לבאנדל, לא תלוי CDN)
- **Zustand** — ניהול state עם שמירה ב-`localStorage`
- **qrcode** — יצירת ברקוד לקוד האישי

## מבנה הפרויקט

```
src/
  data/         נתוני seed — פארקים, ערים, תוכן אקדמיה
  screens/      מסכי האפליקציה (מפה, חברים, כלב, אקדמיה, עוד, שאלון, צ'אט)
  ui/           רכיבים משותפים (אווטאר, bottom-sheet, hook זמן)
  store.ts      state גלובלי + לוגיקת נוכחות/שמחה
  types.ts      טיפוסי הדומיין
```

## הצעדים הבאים (roadmap)

- Backend אמיתי (משתמשים, נוכחות חיה, push) במקום דמו מקומי.
- מקור נתוני פארקים אמיתי מ-OpenStreetMap ו-open-data של עיריות.
- שיתוף מיקום GPS אמיתי וסריקת QR במצלמה.
- דשבורד ניהול לעיריות ושיתופי פעולה עם חנויות.
